# 다왔어 · Almost There

GPS를 기반으로 설정한 목적지에 가까워지면 알람을 울려주는 Flutter 기반 목적지 도착 알림 앱입니다.

대중교통 이용 중 목적지를 지나치지 않도록 도착 전에 알림을 받을 수 있으며, 여러 목적지를 저장한 뒤 필요한 알람만 개별적으로 활성화할 수 있습니다.

목적지 정보는 **Hive**, 테마와 백그라운드 위치 감지 스냅샷 등 일부 설정 정보는 **SharedPreferences**를 통해 기기에 로컬 저장됩니다.

---

## 주요 기능

### 목적지 관리

- 장소 검색 또는 지도에서 직접 위치 지정
- 목적지 이름 및 도착 감지 반경 설정
- 여러 목적지 저장
- 목적지별 알람 활성화·비활성화
- 길게 눌러 여러 목적지 일괄 활성화·비활성화·삭제
- 전체 / 알람 활성화 목적지 필터
- 최근 추가한 순 정렬
- 현재 위치 기준 다음에 알람이 울릴 순서로 정렬

### 지도 및 위치 감지

- 신규 목적지 등록 시 현재 위치 표시
- 현재 위치로 지도 이동
- 지도 다크 모드 지원
- 백그라운드 위치 감지
- 이동 속도와 목적지까지의 거리에 따른 위치 확인 주기 조절
- 위치 수신 중단 시 감지 복구 시도
- 위치 감지 기록을 통한 동작 상태 확인

### 알람

알람 출력 방식을 선택할 수 있습니다.

- 스피커
- 진동
- 이어폰
- 소리와 진동 동시 사용

알람 음량과 진동 세기를 조절할 수 있으며, 알람이 갑자기 최대 강도로 시작하지 않도록 **3초~2분 사이의 점진적 증가 시간**을 설정할 수 있습니다.

알람 시작 시 다른 미디어의 일시정지를 요청하며, 알람으로 인해 변경된 미디어 음량은 알람 종료 후 기존 상태로 복원합니다.

이어폰 알람은 이어폰 출력이 실제로 확인된 경우에만 재생되며, 이어폰 연결이 해제되면 즉시 중단됩니다.

### 알람음 관리

- 기본 알람음 사용
- 사용자 음악 추가
- 알람음 미리듣기
- 알람음 재선택
- 여러 음악 일괄 삭제

### 알람 화면

알람 화면의 배경을 직접 설정할 수 있습니다.

- 움직이는 그라데이션
- 사용자 지정 색상
- 사진
- 동영상

최근 사용한 배경 4개를 저장하여 다시 선택할 수 있습니다.

목적지 편집 화면에서는 **알람 화면 미리보기**를 지원하며, 설정의 **도착 알림 테스트**를 통해 실제 이동 없이 알람 동작을 확인할 수 있습니다.

알람이 실행되면 다른 앱을 사용하고 있거나 잠금 상태인 경우에도 가능한 범위에서 알람을 표시하며, 화면 하단의 슬라이더를 밀어 종료합니다.

## 사용 방법

기본 사용 순서는 다음과 같습니다.

**권한 설정 → 목적지 저장 → 알람 스위치 활성화 → 목적지 도착 → 슬라이더로 알람 종료**

1. 앱 실행 후 필요한 위치 및 알림 권한을 설정합니다.
2. **목적지 추가**를 선택합니다.
3. 장소를 검색하거나 지도에서 원하는 위치를 지정합니다.
4. 목적지 이름과 도착 감지 반경을 설정합니다.
5. 목적지를 저장합니다.
6. 목록에서 사용할 목적지의 알람 스위치를 켭니다.
7. 목적지에 가까워지면 알람이 실행됩니다.
8. 알람 화면 하단의 슬라이더를 밀어 알람을 종료합니다.

## Android 권한 및 동작

Android에서는 정상적인 백그라운드 위치 감지를 위해 위치 권한을 **항상 허용**으로 설정하고 알림 권한을 허용해야 합니다.

다음 설정은 Android 버전 및 기기 제조사의 백그라운드 실행 정책에 따라 알람 전달 안정성을 보완하는 데 사용됩니다.

- 위치 권한
- 알림 권한
- 전체 화면 알림
- 다른 앱 위에 표시
- 배터리 최적화 제외

일부 제조사의 Android 기기는 자체적인 절전 또는 백그라운드 앱 제한 정책을 적용하므로 동일한 설정에서도 동작 방식에 차이가 발생할 수 있습니다.

Android에서는 foreground location service를 이용해 백그라운드에서 위치를 확인하고 목적지까지의 거리를 계산합니다.

설정한 도착 조건이 충족되면 알람을 실행합니다.

## iOS 동작

iOS에서는 시스템의 위치 백그라운드 모드가 허용하는 범위에서 목적지 감지를 수행합니다.

사용자가 앱을 직접 강제 종료한 경우에는 iOS 정책상 지속적인 위치 감지를 보장할 수 없습니다.

또한 iOS에서는 Android와 같은 방식으로 다른 앱 위에 전체 화면을 강제로 표시할 수 없으므로, 알림을 탭하여 알람 화면으로 진입하는 방식으로 동작합니다.

## 데이터 저장

앱의 주요 데이터는 사용자 기기에 로컬 저장됩니다.

### Hive

- 목적지 정보
- 목적지별 알람 설정 등

### SharedPreferences

- 테마 설정
- 백그라운드 위치 감지 관련 스냅샷
- 기타 경량 설정 정보

사용자가 추가한 미디어 또한 앱에서 관리되는 로컬 데이터로 저장됩니다.

편집 중 변경 사항이 있는 상태에서 화면을 벗어나는 경우 변경 내용을 확인하는 절차가 표시됩니다.
